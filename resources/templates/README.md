# resources/templates

这个目录里放两类「模板」：**教室布局的快速模板**和**学生名单的导入模板**。

---

## 1. 学生名单导入模板

| 文件 | 说明 |
|---|---|
| `学生名单导入模板.xlsx` | 给老师填写的名单表格：`名单` 页（只有表头）+ `填写说明` 页 + `示例` 页 |

用法：填好后在程序里用 **文件 → 导入学生名单…**（或左侧面板「导入 Excel」）读入，
表头会自动对应好字段，直接确认即可。

* 程序里随时可以重新生成一份：**文件 → 下载名单导入模板…**，或左侧面板底部的「名单模板」按钮。
* 想改模板的列、示例数据、填写说明，请编辑 `app/storage/roster_template.py`，
  然后运行 `scripts/make_templates.py` 重新生成本文件。

> 注意：模板的第二、三张表（填写说明 / 示例）只是给人看的，
> 程序导入时**只读第一张表**，所以可以放心把带示例的文件发给学生或同事。

## 2. 教室布局快速模板（`*.json`）

程序「编辑 → 教室布局」对话框顶部的「快速模板」下拉，就是由本目录的 `*.json` 生成的。
教师可以自己复制一份改数值，重启程序即可在列表里看到（名称会显示为 JSON 里的 `name`）。

```json
{
  "name": "3 组 × 6 行 × 2 列",
  "description": "最常见的三组六排布局，适合 36 人以内班级",
  "groups": 3,
  "rows": 6,
  "cols": 2,
  "podium_side": "top",
  "card_size": "medium",
  "gap_after": 1
}
```

字段与取值范围：

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 建议 | 下拉里显示的名字；缺省用文件名 |
| `groups` | ✅ | 分组数，1 ~ 6 |
| `rows` | ✅ | 每组行数，1 ~ 12 |
| `cols` | ✅ | 每组列数，1 ~ 8 |
| `description` | ❌ | 备注，目前仅作说明 |
| `podium_side` / `card_size` / `gap_after` | ❌ | **当前版本尚未从模板读取**，沿用对话框里的默认值（讲台在顶部、中号卡片、组间距 1） |

规则：

* 只读取 `*.json`，文件名随意（本目录里的 `.xlsx` 不受影响）；
* 数值超出范围的模板会被忽略，同一组「组数 × 行数 × 列数」只出现一次；
* 目录缺失、文件损坏或全部模板被忽略时，程序会自动回退到内置的 8 个常用模板，
  所以删掉本目录也不会导致程序出错。
